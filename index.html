ইনস্টল করার নিয়ম

  1. ওপরের ডাউনলোড করো বাটন চাপো। ফাইলের নাম app-debug.apk।
  2. ডাউনলোড শেষ হলে ফাইলটা খুলে Install চাপো।
  3. অ্যাপ খুলে Create account চাপো। নাম, পছন্দের ID, ইমেইল আর ৬ অক্ষরের পাসওয়ার্ড দাও।
  4. Allow notifications এলে Allow চাপো, নইলে মেসেজের নোটিফিকেশন পাবে না।
  5. নিচে Find ট্যাবে বন্ধুর ID লিখে Search করো, তারপর Message চাপো।

"App not installed" আসছে

আগের HafizZone অ্যাপ থাকলে Uninstall করে নতুনটা ইনস্টল করো। ফোনের জায়গা (storage) কম থাকলে কিছু ফাইল মুছো। ডাউনলোড অর্ধেক হলে আবার নামাও।

"This ID is already taken" আসছে

অন্য একটা ID বেছে নাও, যেমন নামের সাথে সংখ্যা জুড়ে। ID-তে ছোট হাতের ইংরেজি অক্ষর, সংখ্যা আর _ চলবে।

বন্ধুর ID সার্চ করলে "No user found" আসছে

ID ছোট হাতের অক্ষরে লেখো, স্পেস বা @ ছাড়া। বন্ধু অ্যাকাউন্ট খুলেছে কিনা দেখো।

নোটিফিকেশন আসছে না

Settings → Apps → HafizZone → Notifications চালু আছে কিনা দেখো। একই জায়গায় Battery-তে Unrestricted বেছে নাও। Xiaomi, Oppo, Vivo, Realme ফোনে Autostart চালু করো। অ্যাপ Force stop করবে না, আর লগআউট করা থাকলে নোটিফিকেশন আসবে না।

মেসেজ যাচ্ছে না

ইন্টারনেট (ডাটা বা ওয়াইফাই) চালু আছে কিনা দেখো, তারপর আবার Send চাপো। অ্যাপ চালাতে সবসময় ইন্টারনেট লাগে।

নতুন ভার্সন এলে আগের অ্যাপ Uninstall করে নতুনটা ইনস্টল করো। একই ইমেইল আর পাসওয়ার্ডে লগইন করলে অ্যাকাউন্ট আর মেসেজ ফিরে পাবে। iPhone-এ এই অ্যাপ চলে না।
